# 穗豐村大冒險 · 雙人協力遊戲

一款純前端、免安裝、可離線遊玩的雙人協力闖關小遊戲。
以「鄉村永續」為主題，兩位玩家在同一台電腦上並肩作戰，一同破解 8 道關卡。

## 如何遊玩

直接用瀏覽器開啟 `index.html` 即可（支援 `file://` 直接開啟）。
建議使用 Chrome、Edge 或 Firefox。

> 首次點擊畫面時會啟動音效（瀏覽器政策限制），若沒有聲音，請點一下畫面任意處。

## 遊玩方式

- **玩家 1**：使用 **滑鼠**
- **玩家 2**：使用 **鍵盤**（方向鍵 ←→↑↓、空白鍵；節奏關卡為 ← →）

兩人**同時**在同一畫面合作，沒有先後輪流。每關都有時間限制，時間內完成即可過關；
失敗或時間到都能**無限重試**，但剩餘時間與失誤會影響 ★ 評價。

## 角色與加成

開場由兩位玩家各自選擇角色並取名。角色會為**全隊**帶來被動加成：

| 角色 | 類型 | 加成 |
| ---- | ---- | ---- |
| 🌾 憨農哥 | 力量型 | 動作關卡 +3 秒 |
| 🔮 智囊妹 | 智慧型 | 腦力關卡 +15 秒 |
| 🎋 樂天翁 | 均衡型 | 各關卡 +1.5 秒 |

## 故事

穗豐村遭遇旱災、蝗害與失竊，唯有湊齊「水源、稻穗、祝福」三樣聖物，
才能讓村莊重獲生機。兩位冒險者將在八道關卡中逐步集齊聖物，最後迎來豐收慶典。

## 技術說明

- 純 HTML / CSS / JavaScript，**無需建置**、無外部依賴
- 音效由 **Web Audio API** 即時合成（無音檔、可離線）
- 動作關卡使用 Canvas 繪製；腦力關卡使用 DOM / SVG
- 採傳統 `<script>` 載入，確保 `file://` 可執行
